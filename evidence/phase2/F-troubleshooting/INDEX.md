# Extension F — Faculty-injected troubleshooting

- [ ] `F1-injected-fault-YYYY-MM-DD.txt` — exact fault introduced.
- [ ] `F2-dns-layer-check-YYYY-MM-DD.png` — resolver and A-record checks.
- [ ] `F3-tcp-layer-check-YYYY-MM-DD.png` — port/connectivity checks.
- [ ] `F4-tls-layer-check-YYYY-MM-DD.png` — certificate/issuer/trust checks.
- [ ] `F5-application-layer-check-YYYY-MM-DD.png` — HTTP status, headers, and logs.
- [ ] `F6-correction-YYYY-MM-DD.png` — fix or isolation applied.
- [ ] `F7-final-verification-YYYY-MM-DD.png` — service working after diagnosis.

The diagnosis order must remain DNS → TCP → TLS → application.
