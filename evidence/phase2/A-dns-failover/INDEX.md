# Extension A — Backup DNS evidence

- [ ] `A2-client-resolvers-YYYY-MM-DD.png` — client lists primary and backup DNS.
- [ ] `A3-primary-lookup-YYYY-MM-DD.txt` or `.png` — normal lookup through primary.
- [ ] `A4-primary-stopped-lookup-YYYY-MM-DD.txt` or `.png` — lookup succeeds with primary stopped.
- [ ] `A5-dns-recovery-YYYY-MM-DD.txt` or `.png` — primary restarted and resolver order restored.
